# Olo'Kafu'áng — сайт клана

Статический сайт клана с главной страницей, составом, расписанием, правилами и панелью управления.

## Запуск

Сайт использует `fetch()` для загрузки `data/default-data.json`, поэтому открывай его через веб-сервер, а не двойным щелчком по HTML-файлу. Для локальной проверки можно запустить из папки проекта:

```bash
python -m http.server 8000
```

Затем открой <http://localhost:8000>.

## Публикация на GitHub Pages

В репозитории выбери **Settings → Pages**, укажи ветку `main` и папку `/ (root)`. После публикации сайт будет доступен по адресу GitHub Pages этого репозитория.

## Панель управления и данные

Открой `admin.html` и введи пароль из `js/config.js`. Панель позволяет менять описание и ссылки клана, правила, состав и сессии, а также импортировать и экспортировать JSON.

Это статический сайт без сервера: изменения из панели сохраняются только в `localStorage` текущего браузера. Чтобы опубликовать их для всех посетителей:

1. В панели открой **Импорт и экспорт → Экспорт JSON**.
2. Замени файл `data/default-data.json` в репозитории скачанным файлом.
3. Отправь изменения в GitHub; GitHub Pages обновит сайт после сборки.

Пароль панели хранится в JavaScript-файле и не защищает данные от посетителей, которые умеют просматривать исходный код. Не используй его для защиты конфиденциальной информации.
